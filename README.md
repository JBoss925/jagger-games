# Jagger Games

Standalone repository for [games.jaggerbrulato.com](https://games.jaggerbrulato.com) — six browser games and daily puzzles (**Jordle**, **Jolor**, **Jinx**, **Judoku**, **Jigsaw**, and **Domes**) built on the shared [`jagger-ui`](https://github.com/JBoss925/jagger-ui) design system submodule.

## Development

```bash
git clone --recurse-submodules https://github.com/JBoss925/jagger-games.git
npm install
npm run dev
```
